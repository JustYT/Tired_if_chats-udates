# Инструкция для Codex: Саммаризатор чатов

Для первой установки используй исходный архив
`chat-summarizer-bootstrap-v2.3.0.tar.gz` из репозитория
`JustYT/Tired_if_chats`. Прочитай README.md внутри архива. Не устанавливай
приложение поверх существующей службы и не удаляй базу или профиль Codex.

В архиве нет приватного ключа обновлений. Встроенный `app/release_signing.pub`
— публичный ключ проверки подписи, его безопасно передавать с кодом. После
установки Саммаризатор читает публичный репозиторий выпусков через HTTPS,
проверяет подпись тега и только затем готовит обновление. Установка требует
кнопки владельца и откатывается при сбое проверки здоровья.

Проверь Splitty, пользовательскую службу и `/api/health`. Для браузера открой
SSH-туннель; не публикуй HTTP наружу. Подключай только токены владельца ВМ из
его окружения Стефании через `connect-remote.py`; не печатай и не сохраняй их
значения. Вход Codex выполняет сам владелец через интерфейс.
